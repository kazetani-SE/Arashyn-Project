# Arashyn

A component-based multilingual grammar learning platform that helps learners search, organize, practice, and track grammar more effectively.

## About

Arashyn treats grammar as a structured system rather than a collection of static lessons.

Each grammar pattern is decomposed into reusable components such as:

* Keywords
* Word Classes
* Conjugations / Forms

This allows learners to find grammar using partial information, manage their own grammar collections, and learn through structural interaction.

---

## Features

### Grammar Search

Search grammar using:

* Keywords
* Word classes
* Conjugation forms
* Structural patterns

Example:

```text
V-て + ほしい
```

---

### Personal Grammar Library

* Save grammar for later study
* Organize grammar collections
* Quickly revisit previously learned patterns

---

### Grammar Customization

Personalize saved grammar by:

* Adding notes
* Writing explanations
* Attaching examples
* Highlighting important details

---

### Component-Based Practice

Practice grammar through structural exercises such as:

* Identifying missing components
* Choosing correct forms
* Reconstructing grammar patterns

---

### Progress Tracking

Track:

* Learning status
* Familiarity level
* Review history

---

## Core Idea

Instead of storing grammar as plain text:

```text
N + V(て) + ほしい
```

Arashyn stores each part as structured data:

```text
Grammar
├── Keyword
├── Word Class
└── Form
```

This enables advanced search, practice generation, and future intelligent learning features.

Arashyn aims to transform grammar from scattered information into a structured personal learning system.
